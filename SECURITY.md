# Seguridad

No adjuntes secretos, archivos de clientes o volcados de bases de datos en issues. Para una vulnerabilidad, utiliza el canal de reporte privado de GitHub si está habilitado o contacta con el autor a través de su web. No publiques una prueba que exponga datos de terceros.

Esta edición incluye controles concretos descritos en la documentación y pruebas locales. No cuenta con una auditoría de seguridad externa, pruebas de carga ni una garantía de adecuación a un servicio comercial. Antes de exponer un servidor, configura HTTPS, actualizaciones, copias de seguridad, límites de solicitudes y tratamiento de datos según tu uso.

`.env*`, bases de datos, archivos de clientes, dependencias y compilaciones están excluidos de Git. Si compartes capturas, usa únicamente datos ficticios. Las dependencias deben mantenerse actualizadas.
